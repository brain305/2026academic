# 환율 변동에 따른 기업 영업이익률의 조건부 예측과 재무건전성 분석

## 연구 질문
> 환율 충격(원화 약세)이 발생했을 때, **현금창출력**과 **단기부채 상환능력**이 높은 기업은
> 영업이익률의 악화 폭이 상대적으로 작은가?
 
원/달러 환율이 일정 수준 변한다는 조건을 주었을 때 기업별 영업이익률 변화를 예측하고,
재무건전성이 그 변화 폭을 완화하는지를 검증한다.

**예시 질문**: "원/달러 환율이 5% 상승해 그 수준이 유지된다면, 같은 업종이지만 현금창출력이
다른 A기업과 B기업의 다음 분기 영업이익률은 각각 얼마나 달라질까?"

## 1. 데이터
### 1.1 기업 재무 데이터
| 항목 | 내용 |
|---|---|
| 출처 | OpenDART 공시정보 활용마당 → **재무정보 일괄다운로드** |
| 형식 | TXT (탭 구분, `cp949` 인코딩) |
| 기간 | 2016 ~ 2025 (OpenDART 재무 데이터는 2015년부터 제공) |
| 단위 | 분기 (1분기·반기·3분기·사업보고서) |
| 대상 | IFRS XBRL 제출 유가증권·코스닥 상장사 + IFRS 적용 주요 비상장사 |

### 1.2 기업 마스터 정보
| 항목 | 내용 |
|---|---|
| 출처 | OpenDART **기업개황 API** (`company`) |
| 호출량 | 기업당 1회 (전 상장사 약 2,700회, 1회만 수집 후 재사용) |
| 용도 | 결산월 필터, 업종 통제변수, 상장시장 구분 |

### 1.3 수집 필드
| 필드 | 의미 | 용도 |
|---|---|---|
| `corp_code` | DART 고유번호 8자리 | **기본 키** |
| `corp_name` | 회사명 | 식별 |
| `stock_code` | 종목코드 | 외부 데이터 연결(보조) |
| `acc_mt` | 결산월 | 12월 결산 필터 |

| `est_dt` | 설립일 | 업력 |

### 1.4 공시일 정보
 
| 항목 | 내용 |
|---|---|
| 출처 | OpenDART **공시검색 API** |
| 용도 | 보고서 접수일자 → **미래 정보 누수(look-ahead bias) 방지** |

재무 수치만으로는 언제 시장에 알려졌는지를 알 수 없다. 분기보고서는 분기 종료 후 약 45일,
사업보고서는 약 90일 뒤 공시되므로, 결산기준일 기준으로 환율을 붙이면 미래 정보를 쓰게 된다.

## 2. 표본 정의
| 기준 | 내용 | 근거 |
|---|---|---|
| 결산월 | **12월 결산법인만** (`acc_mt == '12'`) | 아래 상세 |
| 업종 | 비금융업 (금융·보험 제외) | 재무제표 구조가 근본적으로 상이 |
| 재무제표 | 연결(CFS) | |
| 기간 | 2016 ~ 2025 분기 |


### 왜 12월 결산만 남기는가
 
DART 보고서 코드(`11013`=1분기, `11012`=반기, `11014`=3분기, `11011`=사업보고서)는
**회계연도 기준** 분기를 의미하며 달력상 월을 의미하지 않는다.
 
- 12월 결산 기업의 "1분기보고서" → 1~3월
- 3월 결산 기업의 "1분기보고서" → 4~6월
이를 구분하지 않고 합치면 **같은 행에 서로 다른 달력 기간의 실적이 섞인다**.
환율을 결합할 때 특히 치명적이다. 예를 들어 2022년 3분기 원화 급약세 구간의 경우,
12월 결산 기업에는 7~9월 평균 환율이 붙어야 하지만 3월 결산 기업의 같은 기간은
그 회사의 2분기라 다른 보고서에 들어 있다. 결산월을 무시하면 충격과 성과가 어긋나 계수가 희석된다.
