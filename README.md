# 환율 변동에 따른 기업 영업이익률의 조건부 예측과 재무건전성 분석

## 연구 질문
> 환율 충격(원화 약세)이 발생했을 때, **현금창출력**과 **단기부채 상환능력**이 높은 기업은
> 영업이익률의 악화 폭이 상대적으로 작은가?
 
원/달러 환율이 일정 수준 변한다는 조건을 주었을 때 기업별 영업이익률 변화를 예측하고,
재무건전성이 그 변화 폭을 완화하는지를 검증한다.

**예시 질문**: "원/달러 환율이 5% 상승해 그 수준이 유지된다면, 같은 업종이지만 현금창출력이
다른 A기업과 B기업의 다음 분기 영업이익률은 각각 얼마나 달라질까?"
